# KitchenOS v5.7.2

- Live Cooling now has a clear Finish Cooling action.
- A finished live record becomes PASS only when target temperature and time are compliant; otherwise it creates an action-required record.
- Cooling product cards show only the product name.
- Manual start-temperature entry is validated and selects its default value for replacement.
- Cooling report details use the normal plain report layout instead of boxed tiles.
- Bottom navigation is hidden on operational entry/report screens so it cannot cover confirmation controls.
