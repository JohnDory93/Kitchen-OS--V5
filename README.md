# KitchenOS v5.8.0 — Hot Holding

Open `index.html` in Safari or any modern browser.

## Added

- Hot Holding operational workspace.
- Product-only selection cards with search.
- Shared draggable temperature wheel, defaulting just above the configured safe minimum.
- Automatic PASS / ACTION REQUIRED decision.
- Corrective-action workflow for readings below the limit.
- Today's Hot Holding reports and simple report details.
- Editable recorded time for entering checks previously written on paper.
- Per-product Hot Holding minimum in Management → Food & Production.
- Global Hot Holding default for new products.
- Hot Holding can be shown or hidden in Management → Workspaces.

The default safe minimum is 63°C and can be changed per product.
