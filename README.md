# KitchenOS v5.8.1 — Hot Holding Duration

Hot Holding now records how long food has been held.

- Choose the holding start time.
- Choose the temperature-check time.
- KitchenOS calculates the duration automatically.
- Today’s records show the holding duration.
- The report shows started time, checked time, duration, temperature, limit, result, corrective action, and note.
- Cooking and Cooling workflows remain unchanged.
